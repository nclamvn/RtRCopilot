## Defects found and remediated

1. `restore-data.sh` incorrectly expected row-level immutable triggers to throw
   on empty tables. PostgreSQL does not invoke a row trigger when an `UPDATE`
   matches zero rows. Verification now checks 13 privilege denials and three
   enabled immutability triggers independently. The complete restore then
   passed.
2. Deploy/rollback scripts wrote only to the production-shaped repository
   ledger. `RTR_DEPLOY_DIR` now permits an isolated drill ledger.
3. Load fixture seeding depended on host DNS for `rtr.local`. It now uses an
   explicit local ingress resolution and supports a non-default HTTPS port.
4. K6 `--summary-export` serialized the authenticated setup cookie into tracked
   evidence. Both load runners now invoke a fail-simple JSON redactor, and all
   current summaries contain only `[REDACTED]` instead of session material.
