host-only DocumentOS admission/link/publication hooks and current linked output

Contractor chose **no native SDK cancellation sweep** in this slice. Domain

arbitrary active-workflow migration/multi-host failover/production DR is not
claimed. Real external adapters/LLM/MCP deployment remain outside this TIP.

above and repaired only after Contractor authorization. Retained current-source
