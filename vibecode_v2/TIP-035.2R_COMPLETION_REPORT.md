## Outcome

TIP-035.2R fixed the two identified architectural gaps without calling an
external LLM:

1. Profile completeness is no longer inferred from citation presence alone.
   Ontology facets can declare equivalent material coverage groups. Only groups
   found in that facet's authorized evidence become mandatory. Generation,
   repair and the final coverage state share the same contract.
2. Exact governed collection enumeration now takes a deterministic query-plan
   fast lane. For the `PRD-023` shape, the 16-item RtR product collection remains
   bound while the external query-rewrite call count becomes zero.

PRD-023 or any specific question. HERA's application-count checkpoint is
curator data in the enterprise ontology and the same schema supports future
products, policies, projects, customers and other enterprise domains.
