## Constraints and decisions

Do not install a new workflow runtime in this TIP; selection is TIP-054.4a.
No live LLM/embedding, real connector, data admission, production operation,
commit or push is inferred. Do not weaken policy/currentness or introduce
unbounded retries to achieve apparent availability. Recovery ownership must
fence final writes and cleanup; timeout alone is not sufficient correctness.

Prefer existing schema fields if a safe atomic ownership contract can be
expressed. An additive bounded lease/attempt migration for existing render
jobs is within this approved recovery scope; document its necessity and test
rollback. New business/action tables belong to later TIPs.

Use dedicated disposable database/container names and explicit credentials for
synthetic local tests; do not inspect private env values or copy real data.
Retain failures from pre-patch reproduction. The new 96-scenario catalog is
design evidence; only actual exercised cases may be reported executed.
