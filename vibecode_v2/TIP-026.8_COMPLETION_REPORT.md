# TIP-026.8 — Completion Report

## Outcome

HERA definition queries now produce a governed, substantially complete entity
profile instead of a single-record definition. The behavior is implemented as
a reusable ontology contract: any future product, policy, project, customer or
other enterprise entity can opt into the same profile-answer architecture by
binding named facets to approved SOT records.

## Delivered

- Added optional ontology profile facets with stable facet IDs, bilingual
  presentation labels and provenance-bound record keys.
- Upgraded a profiled entity definition from `point/direct` to
  `bounded/summary`, while preserving concise behavior for unprofiled entities.
- Bound profile records through the existing authorization, DLP, currency and
  lineage controls; the profile contract is not an access-control bypass.
- Reserved authorized evidence across facets so broad profile answers are not
  reduced to the highest-scoring definition snippet.
- Required the final answer to use at least one citation from every configured
  facet. Missing coverage triggers one repair attempt and then honest abstention.
- Allowed only exact curator-declared bilingual labels as uncited structural
  headings; arbitrary uncited prose remains rejected by grounding verification.
- Prevented an LLM query planner from injecting governed collections into
  non-enumeration questions, including conversational follow-ups.
- Preserved source/version-scoped questions as narrow queries instead of
  silently expanding them into the full entity profile.

## HERA profile contract

The current governed profile spans ten facets:

1. Overview and role.
2. Current specifications and the 1-4-14 identity.
3. Deployment and field setup.
4. Control ecosystem through HeraHub.
5. Sensing ecosystem through HeraSight.
6. Governed application space.
7. Compliance and Blue UAS status.
8. Maintenance schedule.
9. Warranty.
10. Product roadmap.

No HERA-specific branch or answer prose was added to planner, retrieval or
synthesis code. HERA is the first configured entity; the mechanism is
enterprise-general.

## Live outcome

The real local stack, configured quality LLM and current SOT successfully
answered `HERA là gì?` as a ten-facet dossier with deep citations. In the same
conversation, `thế nó bay được bao lâu?` correctly resolved the HERA context
and returned the governed 56-minute value rather than inheriting an unrelated
catalog intent.

## Vibecode influence

The Vibecode acceptance boundary was applied at the data contract and verifier
layers, not as a prompt-only patch. Completeness is now measurable from used
evidence markers, and a visually fluent but incomplete answer cannot pass as a
complete entity profile.
