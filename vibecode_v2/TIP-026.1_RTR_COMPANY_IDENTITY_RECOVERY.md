# TIP-026.1 — RtR Company Identity Recovery

**Priority:** P0 trust hotfix
**Depends on:** TIP-024.7, TIP-025, TIP-026
**Working directory:** `/Users/os/RtR/KnowledgeBase/RtR_Copilot`

## Context

The production-like local UI answered `rtr là gì` with the `RTR DroneVerse`
application record (`L3F.4.007`). The approved corpus already contains the
company definition in `L3F.ENT.002`, but the active bootstrap ontology contains
only product entities. Therefore `RtR` is treated as an open lexical query
instead of the exact identity of `Real-time Robotics`.

This is a false-grounding defect in entity identity and evidence selection, not
a missing-answer problem and not a UI defect.

## Task

1. Register Real-time Robotics as a governed company entity using the existing
   domain-agnostic ontology contract.
2. Make common approved company-name variants resolve to the same stable entity
   without adding a question-specific branch in code.
3. Add a permanent live-corpus definition gate that requires the company record
   and rejects the DroneVerse record for this intent.
4. Verify the exact UI/API question against the running local stack after the
   backend image is rebuilt.

## Acceptance criteria

- **AC-01 — Identity:** Given `rtr là gì`, query planning resolves exactly one
  entity: `Real-time Robotics`, type `company`, domain `company`.
- **AC-02 — Alias invariance:** `rtr`, `RtR`, `RTR`, `Real time Robotics` and
  `Real-time Robotics` resolve to the same stable entity id.
- **AC-03 — Evidence precision:** For the definition question, live retrieval
  ranks `L3F.ENT.002` first and never accepts `L3F.4.007` as the definition.
- **AC-04 — Grounded answer:** The live Ask response is grounded/evidence-only,
  cites `L3F.ENT.002`, describes the company, and contains no DroneVerse answer.
- **AC-05 — Regression:** Existing HERA, VEGA, OmniSight, ambiguity and unknown-
  entity gates remain green; backend lint, types and relevant tests pass.
- **AC-06 — Governance boundary:** No active ontology revision, SOT record, ACL
  or source document is mutated by this hotfix. The packaged registry remains a
  bootstrap fallback until a governed active revision exists.

## Constraints

- Do not hard-code the literal question in retrieval or answering code.
- Do not weaken citation, authorization, freshness, relevance or abstention
  gates.
- Do not make `RTR DroneVerse` an alias of the company.
- Preserve all uncommitted TIP-026 campaign artifacts.
