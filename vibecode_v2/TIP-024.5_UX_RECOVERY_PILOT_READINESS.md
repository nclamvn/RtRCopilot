## CONTEXT

TIP-024 made the pilot corpus materially real, but the user-facing path still
exposes implementation structure before user intent. The pre-flight UX audit
found four release blockers:

1. `/` opens Files although asking/searching is the product's primary job;
2. the global search affordance is only a command filter, not a knowledge
   entry point;
3. Ask permanently allocates 392 px to evidence and places the composer above
   long history/answers, producing poor first-screen task completion;
4. responsive rules are based on the viewport instead of the space left after
   the 264 px shell, causing clipped Knowledge Ops at 1280 px and a false blank
   row in Files on mobile.

The audit also found role-inappropriate navigation, digest-like conversation
labels, 28 sub-44 px mobile targets, and a mixed Inter/Arial Narrow type system.
API, policy, evidence and provenance contracts are healthy and remain frozen.

## PRODUCT DESIGN DIRECTION

- **Subject:** an enterprise knowledge lens, not a generic dashboard.
- **Primary audience:** any authenticated RtR employee; curator/admin tools are
  progressively disclosed by role.
- **Primary job:** ask or search once, read a clear answer, inspect the proof
  trail when needed.
- **Layout:** a centered 760–860 px conversation stream; sticky composer;
  evidence as an on-demand right proof drawer; single-column fallbacks when the
  shell leaves insufficient content width.
- **Visual language:** strictly achromatic graphite/paper surfaces; primary
  actions invert black/white, while hierarchy comes from luminance and
  provenance from solid/dashed/dotted/double keylines; one Inter/system stack.
- **Signature interaction:** compact citation chips open and focus the exact
  evidence entry, preserving provenance without turning metadata into the
  dominant surface.

## DECISIONS LOG

| ID | Decision | Rationale |
|---|---|---|
| D-024.5-01 | Preserve all backend/API contracts | UX recovery must not weaken policy or provenance |
| D-024.5-02 | A non-empty global query offers `Ask Copilot` as the first result | Delivers universal entry now without inventing a second search API |
| D-024.5-03 | Keep file query parameters at `/` routed to Files; bare `/` routes to Ask | Existing locator links remain valid while the default job becomes Ask |
| D-024.5-04 | Staff sees Ask/Files/Documents; curator adds Knowledge/Operations; admin adds Admin | Dead-end privileged navigation is a trust failure |
| D-024.5-05 | Do not present a stored SHA digest as a conversation title | The contract exposes metadata, not plaintext; a localized date label is honest and readable |
| D-024.5-06 | Use a CSS recovery layer imported last | Reduces risky mechanical rewrites of the 43 KB legacy sheet while creating one explicit migration boundary |
| D-024.5-07 | Encode SOT/research/private/blocked semantics with line grammar and labels, not hue | Preserves enterprise proof clarity while enforcing a true black/gray/white product identity |

The Homeowner explicitly requested implementation after the QA/QC diagnosis;
that request is the Blueprint checkpoint approval for this bounded recovery TIP.

## ACCEPTANCE CRITERIA

- **AC-024.5.1 — Entry:** bare `/` reaches `/ask`; a legacy root URL containing
  file locator parameters reaches `/files` with those parameters intact.
- **AC-024.5.2 — Universal ask:** typing a phrase in the global palette exposes
  a first action containing that phrase and routes to `/ask?q=…`; Ask prefills
  the composer without auto-submitting.
- **AC-024.5.3 — Query navigation:** clicking a recent conversation while
  already on Ask fetches and renders it without reload.
- **AC-024.5.4 — Role navigation:** staff has no Knowledge Ops/Admin link;
  curator has Knowledge/Operations but no Admin; admin has all six areas.
- **AC-024.5.5 — Ask hierarchy:** at 1280 px the readable stream is at least
  620 px wide and the closed evidence drawer consumes no layout column;
  citation activation opens the drawer and focuses the exact entry.
- **AC-024.5.6 — Responsive:** at 1280 px every `ops-split` detail column is at
  least 240 px; at 390 px Files has no artificial blank grid row and no
  horizontal document overflow.
- **AC-024.5.7 — Touch/type:** core mobile shell, composer, drawer and history
  controls expose a minimum 44 × 44 px target; touched body text is at least
  13 px and ordinary body copy at least 14 px.
- **AC-024.5.8 — Regression:** Web unit, browser, axe, lint, type and production
  build gates pass with zero new P0/P1 finding.
- **AC-024.5.9 — Monochrome premium:** theme tokens and every visible Ask paint
  property are achromatic in dark and light; enabled primary action is
  white-on-black or black-on-white; provenance states remain distinguishable
  through line style and text; no horizontal overflow is introduced.
