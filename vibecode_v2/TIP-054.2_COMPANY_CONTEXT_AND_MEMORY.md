## Deliverable

Authenticated API/service to resolve company entity context, build/re-read a
bounded purpose-specific ContextPacket, and create/read/correct/delete scoped
memory. Actual domain operations, not design-only dataclasses. Add only the
PostgreSQL reference/memory structures needed by the approved Blueprint.

Canonical context derives from the active immutable ontology and permitted
current SOT refs (source key, record key, exact version/digest, owner, validity,
retrieval time). Source-backed relation/owner annotations must retain evidence
and be labelled assertions/projections, not silently promoted facts. Source-key
and entity-ID collisions must be explicit. Unknown/missing domains yield gaps,
not false complete-company status. Never auto-infer factual relationships.

Packets identify current caller, authorized scope, purpose (`proposal`
default; `sales`/`attestation` explicit), bounded byte/token estimate budgets,
entity/source refs, source status and notes. Caller cannot supply authority,
source content or arbitrary policy attributes. Reload current subject and
effective resource lineage ACL before content; enforce SOT use-class and
active/current/temporal validity. Return useful authorized partials and safe
gap labels without denied names/content. Persist refs/identities/digests only;
no long-lived copied source text in packet cache. Revalidate every read and
reuse: security_version alone does not cover resource ACL/purpose revision.
Expired/denied/deleted/superseded material never survives via prior packet.
Deterministic selection/budgets; token figures explicitly estimates, not usage.

Memory supports owner-private and admitted project/department scope using
current subject memberships (no invented workspace membership authority).
Types: explicit preference/task note or labelled inference with source refs;
not canonical fact, policy or permission. Team-scope writes require admitted
owner/role contract; private notes require no curator/per-tool approval.
Use bounded text/TTL/counts, lifecycle revision/expiry/correction/deletion and
recheck referenced sources on reads. Source-dependent note withheld if any
reference no longer permitted/current/purpose-compatible. Correction requires
optimistic revision precondition. Delete/redact note text rather than retain
it in ordinary audit, while preserving safe tombstone/revision metadata.
Untrusted text stays data and cannot set capability/ACL fields. Currentness
and purpose enforcement must not regress broad authorized partial answers.
