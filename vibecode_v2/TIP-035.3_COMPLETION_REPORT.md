## Deviation and recovery

The first generic runtime-refresh command supplied `.env.pilot` but did not
explicitly select the pilot Compose project. Docker therefore selected the
default `rtr-copilot-v2` project, recreated its code-bearing containers and
stopped at a MinIO port conflict with the still-running pilot. No volume was
deleted and no indexing or external operation started.

The primary stack was immediately restored from `.env.demo` and verified at
7/7 healthy on `9b019832e08a`. The pilot refresh was then rerun with both
`COMPOSE_PROJECT_NAME=rtr-copilot-pilot` and
`ANSWER_COMPOSE_PROJECT_NAME=rtr-copilot-pilot`; it completed successfully.

This exposes an operator-safety debt in the generic Make target. Changing that
target during the frozen release campaign would create a new candidate and
invalidate the build-bound TIP-033 evidence, so the code change is deferred and
the explicit project selector is mandatory for the rest of this candidate.
