## DEVIATIONS (all L1, recorded choices)

- D1 — Route name: `/knowledge-ops` (house-style short English route like `/documents`), Vietnamese H1 "Vận hành tri thức". Proxy lives at `src/app/api/governance/[[...path]]/route.ts` per handoff; the house pattern does NOT separate research/admin proxies (document-os is one transparent join), so I kept ONE proxy but added a strict family allowlist (`gaps|governance|research|graduation|admin`) — deliberately tighter than document-os' fully generic join, so the web edge cannot be used as a generic `/api/v1` relay.
- D2 — SOT-plane zone chips: `Gap`/`QueueEntry`/`QueuePage` responses carry **no** zone_label field (backend shape), so SOT chips on gap/queue rows render the literal `zone_label` string returned by the self-labeling dashboard's SOT tiles (`gap_flow.zone_label`), fetched per session; until that response arrives no chip is shown. The client never fabricates a zone: research chips come from each payload's own parse-enforced label, SOT chips from a server-returned constant, and `PRIVATE` is supported vocabulary that renders only if an API ever returns it. This is the closest possible reading of "labels come from API responses, never inferred client-side" given the delivered API; see SUGGESTIONS for the TIP-011 fix.
- D3 — 403 is a **denied state**, not session loss: Files/Documents treat 403 like 401, but governance legitimately returns in-session 403s (`curator_required`, SoD denial). The workspace drops to the login gate only on 401; 403 renders the typed denied panel (which AC-13's "denied states" requires). Typed action failures render `error.code · request_id` verbatim per Builder 4a's guidance.
- D4 — Vietnamese verbs: the five TIP verbs map to triage "Nhận xử lý", assign "Giao cho", decline "Từ chối", proposal composer "Đề xuất nâng cấp", approve decision "Đưa vào cổng phát hành". Gap-answer (not in the TIP's verb list) is "Trả lời bằng bản ghi đã phát hành" to keep the publish-gate doctrine in the label.
- D5 — Effects defer loader calls via `setTimeout(..., 0)` with cleanup — required by the repo's react-hooks `set-state-in-effect` rule and already the Documents-page precedent (its `setTimeout(() => void loadTemplates(), 0)`).
- D6 — Graduation evidence fetch caps at the first 10 linked research records (bounded fan-out); policy-hidden records surface as an explicit partial-state count instead of failing the pane.
