## Source-anchored boundaries and pitfalls

- R9 `recording` (line159) synchronously calls the observer callback and contains
  its failure. R9 `sync`/`asynchronous` (188/215) invoke/await the original outside
  that callback. The reduced exposure must wrap only `recording`, not those whole
  wrappers, pool envelopes, terminal methods or product phases. A callback which
  returns a coroutine only measures coroutine creation; it must not be awaited
  or represented as its later execution duration.
- R9 queue `get` (352) awaits the actual queue outside recording; `wake` (385)
  invokes the original wake outside recording. Captured readiness associates a
  getter only with an actually unique Future/task match. It is not reservation,
  delivery or pure queue time; producer/getter identities remain distinct.
- R9 `begin` and `finish` call request/resource/weak-ID helpers inside recording.
  Their inclusive time is already inside the retained outer interval. Avoid
  additive helper sums, separately ranked p95 sums or subtracting measured cost
  from SLA. Audit `emit` similarly contains JSON/write/flush; analyze their union
  and overlap masks, not four independent additive costs.
- R2 `AuditTailObserver.append` (167) awaits actual append/locks/SQL. Do not wrap
  that as preparation. `emit` (196) does observer-only calculations and immediate
  serialize→write→flush. Its record supplies the original request identity;
  never substitute whichever request/owner is currently live.
- PhaseProfiler closes the HTTP record before finish→serialize→write→flush,
  then resets its context. Preserve that order and actual return timing, original
  staticmethod descriptor and global JSON identity. Closed reference finalization
  is expected post-HTTP evidence, not silently clipped away or relabelled HTTP.
- A queued timer may inherit request context but have no current Task. Preserve
  task/request-null timer origin, distinct no-loop origin, explicit late/unknown
  scopes and rejected inherited parents. No retro-attribution or cross-namespace
  numeric identity joins. Weak detached IDs must not retain Session/facade/carrier.
- Contain only NEW observation faults. Original delegate/result/error/cancellation
  executes exactly once. Restoration/close faults must not replace an original
  primary error; persist typed diagnostic faults and reject completeness.
