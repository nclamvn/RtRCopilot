memory object. It can include20 explicit zero-emission receipts; it does not prove
1,600 observations, original oracle/SLA success or real producer quiescence.

incomplete, without substituting hashes or flags for omitted raw diagnostics.

allocation-failure equivalence exists here. An acknowledged model terminal is not
