# TIP-035.16 — Restore RTO Batching Hardening

## Header

- Date: 14/08/2026
- Depends on: TIP-035.14, TIP-035.15
- Trigger: build-bound restore drill on the release corpus
- Priority: P0

## Context

A fresh manifest-v2 backup of the current 657-object corpus restored with full
integrity but required 326 seconds, breaching the declared five-minute RTO by
26 seconds. Database restore, checksum verification and repository smoke all
passed. The dominant cost was process orchestration: `restore-data.sh` started
one Docker container for every object so it could preserve object-level restore
metadata.

## Requirements

- REQ-035.16-01: preserve `sha256`, `byte-size`, `upload-state` and
  `restore-operation-id` metadata on every restored object.
- REQ-035.16-02: copy all objects through one pinned MinIO client container,
  not one container per object.
- REQ-035.16-03: object keys must cross the host/container boundary without
  delimiter ambiguity or shell interpretation.
- REQ-035.16-04: row counts, object checksums, audit chain, immutable triggers,
  runtime denials and repository smoke checks remain mandatory.
- REQ-035.16-05: the same 657-object archive must restore within 300 seconds to
  an isolated target.

## Acceptance criteria

1. Shell syntax and the release-boundary regression suite pass.
2. The object-copy manifest is NUL-delimited and processed by one MinIO client
   container.
3. The isolated restore reports 657 objects, 100% row counts, 100% checksums,
   valid audit chain, 15 runtime denials, three immutable triggers and 18
   runtime controls.
4. Measured restore time is at most 300 seconds.
5. The isolated database and bucket are deleted only after their operation ID
   is verified; third-party objects preserved must equal zero.

## Decision log

- The failed 326-second run remains disclosed; it is the evidence that exposed
  the scaling defect.
- No integrity check or ownership marker is relaxed to improve the RTO.
- NUL-delimited fields are used because S3 keys may contain spaces, tabs,
  newlines or shell metacharacters.
- External LLM, embeddings, connector activation and production operations are
  outside this TIP.
