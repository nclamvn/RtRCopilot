## Requirements and acceptance criteria

- BKO-001: Both actual SDKs run on Python 3.12 with exact stable pins, package
  provenance/license and applicable vulnerability-check result/limitations.
- BKO-002: One engine-neutral frozen manifest, synthetic payloads, effect key,
  state/receipt oracles and bounded retries/budget rules govern both branches.
- BKO-003: Crash before dispatch, within work and after source effect before
  receipt are injected at real process boundaries; recovery reports accurate
  state with zero duplicate known effects and no fabricated success.
- BKO-004: Duplicate submissions, competing workers and stale ownership cannot
  publish a second effect or stale receipt. Demonstrate final source fencing,
  not only workflow ID deduplication.
- BKO-005: Wait/restart and current approval/input/schema/ACL drift block stale
  work before its effect. A durable checkpoint is not current authorization.
- BKO-006: Timeout, cancellation after partial effect and unsupported ambiguous
  effect report honest partial/cancelled/needs_review state, no blind retry.
- BKO-007: Compatible deployment/version recovery and deliberately incompatible
  work are distinguished; backup/restore of synthetic engine/source state is
  exercised or explicitly not certified. Never claim live-safe upgrades.
- BKO-008: Replayed/retried work charges one finite parent budget, cannot reset
  it or hide unpriced calls; receipt references and outcomes match source state.
- BKO-009: Matched direct/engine trials on local concurrency 1/10/25/50 retain
  all samples, p50/p95/p99, errors, cold startup/recovery separately, process
  memory/idle footprint/config burden and measured DB write/size observations.
  Extra orchestration p95 target <=1s is judged, not assumed. Common synthetic
  provider delay is separated. No extrapolation to production or company scale.
- BKO-010: Hard correctness gates precede performance. ADR selects only an
  eligible candidate from verified evidence, or truthfully leaves choice
  unresolved when required proof is missing. Independent rerun validates raw
  evidence and detects tampering/missing trials/false-success fixtures.

Any untested criterion stays MISSING/deferred; no documentation fills a
benchmark cell. Single-sample quantiles, warm-only timings or unlike service
profiles must be labelled. A failed hard oracle is never waived for speed.
