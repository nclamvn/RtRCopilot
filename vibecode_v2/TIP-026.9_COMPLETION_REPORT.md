# TIP-026.9 — Completion Report

## STATUS

DONE

## OUTCOME

RtR Copilot now treats usefulness as the default answer policy for authorized
employees. Ordinary definitions, lists, summaries and colloquial questions may
return the supported portion of the permitted SOT instead of becoming
all-or-nothing abstentions. Security and factual trust boundaries remain hard:
ACL, DLP, source currency, unresolved conflicts and claim-level citations were
not weakened.

## DELIVERED

- Separated enumeration intent from certified exhaustive coverage.
- Added deterministic explicit-completeness detection. Only wording such as
  `tất cả`, `toàn bộ`, `đầy đủ`, `complete`, `full` or `exhaustive` may create
  a strict completeness contract; the LLM cannot silently escalate it.
- Changed ordinary list questions to bounded best effort while retaining
  governed collection bindings whenever the planner resolves one.
- Changed profile verification to require every facet represented in the
  authorized evidence set, rather than every configured facet regardless of
  availability.
- Preserved the anti-shallow gate: if evidence for a facet is supplied, the
  answer must use and cite that facet.
- Generalized generation and independent-review instructions so supported
  partial content is useful output, not a reason to return `answerable=false`.
- Prevented one low-ranked adjacent retrieval hit from rejecting an otherwise
  correct evidence set. Final entity and citation verification remain strict.
- Added `complete`, `partial` and `not_assessed` response coverage metadata.
- Added a neutral bilingual partial-coverage note to Ask without revealing a
  missing or denied record identity.
- Kept explicit exhaustive requests all-or-nothing and collection-bound.

## REQUIREMENT COVERAGE

8/8 requirements implemented (100%).

## SECURITY INVARIANTS

- Authentication and resource authorization are unchanged.
- Denied or DLP-rejected evidence never enters provider context.
- Current-lineage revalidation still runs before generation and persistence.
- Every rendered factual unit still requires a known citation marker.
- Wrong-entity and unsupported final answers still fail deterministic checks.
- Partial metadata discloses no facet name, record key or denial reason.

## VIBECODE INFLUENCE

The fix was made at the reusable contract, planner, verifier and response
layers rather than as prompt wording or a HERA branch. The acceptance tests
measure useful grounded output and the remaining hard security boundaries
independently.
