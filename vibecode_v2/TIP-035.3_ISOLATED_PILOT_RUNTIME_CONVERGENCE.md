## Context

The isolated pilot has seven healthy long-running containers and a populated
canonical database, but its application runtime does not match the frozen
candidate. `verify-pilot-database.sh` fails because the build identity declared
by `.env.pilot` differs from the running API container.

This is a runtime-convergence task. Existing pilot data and semantic index must
remain in place. The task does not authorize external LLM processing, embedding
generation, corpus reindexing, connector activation or TIP-034.
