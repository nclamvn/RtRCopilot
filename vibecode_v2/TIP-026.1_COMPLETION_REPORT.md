## Deviations and observations

- The first verification probe used lowercase `rtr`, while the UI reproduction
  used mixed-case `RtR`. The legacy CamelCase normalizer split the latter into
  `rt r`, bypassing the correct ontology alias. Verification was reopened,
  normalization was corrected generically, and the exact UI spelling is now a
  required golden case. The earlier READY conclusion was therefore superseded
  until this report's second live verification completed.
- The first full-suite attempt used a minimal Python image and produced two
  environment-only failures: missing Vietnamese PDF font behavior and a
  missing `/workspace/phase1_pilot` mount. Re-running in the production backend
  image with the complete repository mount produced **458/458 executed tests
  passed**. Neither failure involved this change.
- The runtime currently has no active governed ontology revision, so the
  packaged bootstrap registry is authoritative. When a revision is activated,
  it must include this company entity and definition binding; runtime correctly
  does not merge or silently override an active governed revision.
- The live Ask verification created a normal test conversation/answer-run audit
  trail using request id `tip0261-live-rtr-company`. It did not create a
  knowledge gap or modify SOT content.
