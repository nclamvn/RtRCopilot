# TIP-026.2 — Completion Report

**Status:** COMPLETE
**Date:** 2026-08-05
**Scope:** Multiformat viewer fidelity, Office rendition recovery and Files UI

## Outcome

The reported preview failure is resolved in both the product pipeline and the
existing live artifact. `RtR_DaNang_UAV_Briefing.pptx` now opens through a
22-page, 16:9 PDF rendition generated from the original 22 slides. Vietnamese
text, slide composition, images and page order are preserved. The old lossy
rendition remains auditable but is no longer active.

The vertical stack of empty squares was the CSS-only `locator-spine`: a
decorative repeating gradient with no locator data, thumbnails or interaction.
It has been removed. Page/slide location is now represented by a semantic,
keyboard-operable command bar.

## Root cause

1. DOCX and PPTX previews were flattened into an A4 text-only ReportLab PDF.
   This discarded Office geometry and images.
2. The default PDF fonts could not represent Vietnamese reliably, producing
   black replacement squares and corrupt extracted text.
3. The Files workspace nested a permanent tools column inside its existing
   catalog/canvas/provenance layout.
4. The absolute `locator-spine` decoration overlapped that column and looked
   like unexplained UI controls.

## Implementation

- Replaced Office text flattening with sandboxed LibreOffice headless PDF
  conversion while retaining native structured JSON extraction for search and
  evidence locators.
- Installed checksum-pinned Be Vietnam Pro Regular/Bold/Italic/Bold Italic plus
  deterministic common-font fallbacks in the backend image.
- Added page-count, slide-aspect and Vietnamese Unicode coverage gates.
- Normalized PDF metadata and trailer identity so the same source produces the
  same rendition checksum.
- Updated the process sandbox to permit only local `AF_UNIX` IPC required by
  LibreOffice while continuing to deny non-local socket creation.
- Advanced the ingestion pipeline and rendition generator to version 2.
- Added atomic rendition replacement: verified v2 renditions become active;
  prior matching renditions and their derived objects become `superseded`.
- Rebuilt the Files viewer around a compact command bar and dominant canvas.
  Search is now an on-demand drawer instead of a permanent nested column.
- Unified PDF, DOCX, PPTX, image, spreadsheet, video and audio viewer chrome.
- Removed `locator-spine` and added responsive/overflow coverage for all seven
  supported viewer kinds.

## Residual risk

LibreOffice is a high-fidelity Office renderer but cannot guarantee pixel-level
identity when a source uses proprietary fonts absent from the approved runtime.
The current pipeline guarantees the shipped Be Vietnam Pro family, common
fallbacks, page/slide integrity and a fail-closed Unicode threshold. A future
font-governance registry should onboard other company-approved font families as
the enterprise corpus expands.
