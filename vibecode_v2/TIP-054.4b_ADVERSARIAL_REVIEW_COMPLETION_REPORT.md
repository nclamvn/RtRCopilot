## Review findings and changes influenced

The review raised these risks before/while implementation was completed:

- A source-admission callback alone cannot fence later document publication.
  The implementation now uses a persisted host-owned linked-run guard at final
  publication, alongside the canonical renderer's own ownership fence.
- Generated output previously inherited template-only classification/security.
  Narrow action-linked output protection now checks immutable source/purpose
  bindings and current access, including generated history and Files surfaces.
- Receipt/source-link attempt identity needed SQL composite ownership FKs.
- Source job hashes alone cannot authorize changed canonical values; published
  inputs are SQL-immutable and final linked publication additionally rederives
  field values.
- Native completion on a paused domain decision would strand same-ID resume.
  The native workflow now keeps paused state nonterminal with a finite parent
  deadline. Current-byte finite compatible pause/resume/deadline proof passes
  separately from these domain tests; it is not arbitrary workflow migration.
- An unverifiable claimed-completed canonical source must route to needs_review,
  not generic failed/partial. The targeted actual source-state case now passes.

These were source-level review findings until checked; they are not asserted
as previously reproduced production incidents.
