# TIP-027.5 — Completion Report

## STATUS

**IMPLEMENTATION COMPLETE · HERMETIC QA PASS · BOUNDED LIVE RECERTIFICATION PASS.**

The runtime now optimizes provider work at the architecture boundary rather
than trading answer quality for a cheaper model. Exact governed questions take
a deterministic plan, ambiguous questions retain semantic planning, and every
answer still passes the existing evidence and grounding gates.

## COMPLETED OUTPUTS

### 1. Provider-reported usage accounting

- Added a provider-neutral immutable usage model.
- Parses OpenAI input, cached-input, output, reasoning and total tokens.
- Parses Anthropic input, cache-read, cache-creation and output usage.
- Aggregates planner, generator, reviewer, fallback and repair usage inside the
  request context.
- Persists factual usage to answer/audit data and exports Prometheus counters.
- Retains a legacy estimate only for local adapters that return no provider
  usage metadata; external provider accounting no longer relies on character
  count.

### 2. Dual daily budget guard

- Preserved the deployed call-budget Redis key contract.
- Added independent token counters for both subject and global scopes.
- Added governed registry settings for subject/global daily token ceilings.
- Budget audit events include actual calls/tokens and post-debit totals.
- A reached ceiling rejects the next provider-backed ask before additional
  calls. A single in-flight response may finish above the remaining token
  headroom because final usage is only known from the provider response.

### 3. Quality-preserving call reduction

- Exact registered definitions and point attributes bypass the LLM planner.
- Ambiguity, fuzzy aliases, conversation context, comparisons, procedures,
  enumeration and analysis retain LLM planning.
- Point/direct synthesis skips advisory LLM review while deterministic citation,
  entity, evidence-overlap, profile and collection gates remain authoritative.
- Advisory rejection no longer causes another full generation.
- A deterministic grounding failure still receives one bounded repair attempt.
- Reviewer routing now has its own model option, low reasoning and a 256-token
  ceiling rather than inheriting generator cost.
- Output ceilings are contract-aware so short answers do not reserve dossier
  budgets, while complete lists and analysis retain full headroom.

For an exact governed definition, the normal route changes from planner +
generator + reviewer (three provider calls) to one grounded generator call.
This is an upper-bound 67% call reduction for that class, without changing the
final deterministic acceptance gates. Ambiguous questions do not receive this
shortcut.

### 4. Cache-safe query planning

- Added a bounded in-process planner cache keyed by ontology digest and the full
  planner input, including bounded conversation context when present.
- Cache expiry and maximum entries are configurable.
- Ontology changes naturally invalidate prior keys.
- Added stable, non-PII OpenAI prompt-cache keys for planner, generator and
  reviewer routes.

### 5. Spend-safe acceptance campaign

- Added `--max-cases` to the real-world acceptance runner.
- `scripts/run-enterprise-e2e.sh` now defaults to 12 deterministic smoke cases.
- A complete 77+ scenario provider campaign requires the explicit environment
  approval `E2E_APPROVE_FULL=1`.
- The full quality campaign and its thresholds are unchanged; only accidental
  invocation is prevented.

### 6. Live reliability recovery without weaker grounding

- Added targeted HTTP case selection and Playwright grep controls so one failed
  journey can be diagnosed without replaying the whole paid campaign.
- Separated the ordinary 12-record candidate budget from a governed authority
  ceiling of 20. HERA's 13-record profile and the 14-row product collection no
  longer lose required authority records to a generic truncation.
- Registry-approved canonical names and aliases of the actual answer subject
  are treated as presentation labels only; adding any attribute turns the line
  back into a citation-mandatory factual unit.
- The deterministic lexical check remains the baseline. A semantic paraphrase
  with zero literal overlap may pass that one gate only after the independent
  reviewer accepts the exact question, evidence and citation mapping.
- After conservative citation distribution, every still-uncited unit is deleted
  from the draft rather than trusted or assigned a source. Relevance, entity,
  profile and exhaustive-collection gates then evaluate only the surviving
  cited subset. An empty or insufficient subset still fails closed.
- This eliminated the expensive second synthesis call for the live colloquial
  company journey while retaining unknown-entity honest-null behavior.
