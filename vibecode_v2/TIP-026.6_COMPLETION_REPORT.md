# TIP-026.6 — Completion Report

## Outcome

Core answer usefulness is restored for the active RtR pilot corpus. The Ask
path no longer behaves as a random extractive search or rejects an entire
multi-part question because one member lacks detail. It now resolves intent,
retrieves governed authority, synthesizes a useful answer through the approved
LLM, and releases the answer only after deterministic grounding checks.

This is a successful pilot recovery, not a claim that every future enterprise
domain is already covered. New domains still require governed onboarding,
ontology bindings and domain-stratified evaluation.

## Root causes closed

| Root cause | Resolution |
|---|---|
| Non-RtR synthetic sources remained active in the live corpus | Removed their active pointers and superseded their generations; retained history for audit |
| Authority records could fall outside the arbitrary candidate window | Added a bounded, metadata-first, ACL-filtered authority lane |
| LLM-expanded wording could dominate the user's original intent | Original query now owns ranking; expansions are recall-only support queries |
| Accent folding converted Vietnamese words into over-broad stopwords | Corrected normalization and preserved meaningful short enterprise acronyms |
| Collection names were not bound to member evidence | Added governed collection/member bindings and coverage evaluation |
| “All details or refuse” made partial-but-useful answers impossible | Require full governed membership while allowing explicit per-member detail gaps |
| Citation verifier mishandled ordered lists, `TS.`, short verdicts, paragraph-end citations and acronyms | Repaired factual-unit parsing, safe citation propagation and acronym-aware support checks |
| Maximum reasoning was used for simple enumeration | Added intent-sensitive reasoning budgets while retaining review and grounding gates |
| Integration tests could touch the live database | Enforced isolated integration database prefixes |
| Signed cursors accepted non-canonical Base64 variants | Added canonical encoding checks to governance, ingestion and document cursors |

## Final answer architecture

`Question → query plan → ACL-filtered metadata scan → authority lane + bounded
semantic lane → original-query ranking → DLP → evidence relevance → LLM
synthesis → independent LLM review → safe citation normalization →
deterministic grounding/current-lineage/coverage verification → grounded answer
or honest-null`

No LLM output is treated as enterprise truth. The LLM improves interpretation
and expression; evidence, policy, citations and release remain deterministic.

## Security and trust invariants retained

- ACL and external-processing policy are evaluated before content loading.
- Restricted or denied authority records cannot leak through the priority lane.
- DLP, provenance, freshness, current-lineage and deep-citation checks remain
  mandatory.
- Unsupported prose and undeclared citations fail closed.
- Unknown entities create an auditable knowledge gap instead of a fabricated
  answer.
