## Baseline and smallest design

AW-05 context() chooses the last completed model history plus the whole inventory;
Runtime.execute rejects history larger than 512000 bytes. It has no bounded
selection/search context manifest or output dependency freshness panel. Existing
files, artifact versions, exact edit/CAS, DBOS recovery, cancellation, memory
epoch, deletion and snapshot are retained, not replaced by a second agent loop.

One small continuity/context service and a new workflow version are sufficient.
Use local deterministic text search, not vector infrastructure or another model.
Do not generate automatic summaries with a pretend local AI. A user-maintained
brief has separate goal/decisions/remaining fields; agent suggestions stay labelled
draft suggestions and cannot silently become confirmed memory/authority.

## Integration contract

Backend owns all Python code (including runtime, store, API and lifecycle). UI
Builder owns shared neutral TS/CSS, scoped BFF whitelist and browser/unit tests.
Agree deviations at Contractor, not by changing the contract silently.

- GET `/workspaces/{wid}/brief`: `{revision, goal, decisions, remaining}`.
  POST same path: those three text fields, `expected_revision`, `request_id`.
  User-authored fields; CAS, owner scope, bounded strings, idempotency.
- POST `/workspaces/{wid}/context-preview`: `{message, references:[], target:null}`.
  References `{kind:"file"|"artifact",id,version?}`; target artifact reference or
  null. Explicit references are validated/pinned, not silently dropped. Empty
  selection allows a deterministic bounded automatic selection with explanation.
  Response includes selections/chunks, omissions/limits, byte counts and digest.
- GET `/workspaces/{wid}/search?q=...`: local bounded file/current-artifact text
  matches, opaque scoped IDs, snippets and versions. Never execution authority.
- POST `/runs`: existing fields plus optional `context` containing
  `{references:[],target:null}`. Omitted preserves compatibility. Request identity
  binds choices. New runs use bounded context and a durable input manifest, recent
  safe conversational turns, project brief and existing live memory. Large history
  is not blindly injected. Full transcript stays saved. Clearly label omitted old
  history; don't claim complete reading. Imported archived text is not SDK history.
- GET `/runs/{rid}/context`: actual run snapshot and coverage/read ledger; owner
  scoped, no credentials/provider protocol or chain of thought.
- POST `/workspaces/{wid}/source-replacements`:
  `{old_file_id,new_file_id,request_id}`. Both already uploaded immutable files in
  same workspace; explicit, idempotent, no cycles/ambiguous duplicate replacement.
  Preserve bytes/old links. Label as user-recorded replacement, not truth.
- GET `/artifacts/{aid}/dependencies?version=N`: exact recorded reads/context
  dependencies with known/unknown coverage and stale reasons. Historical versions
  stay intact; no claim that syntactic lineage is semantic completeness.

Manifest generation must be snapshotted durably once, not recomputed on replay.
Scoped chunk reads update a read ledger without bloating event payloads; output
publication records actual used source/artifact versions and current target CAS.
Pinned historical artifact versions remain readable. A concurrent source change
is surfaced, and a stale target cannot overwrite a newer artifact. An unrelated
source replacement must not invalidate everything. Existing legacy outputs show
unknown lineage rather than fabricated verified dependencies.

Deleted memory, brief and workspace cannot revive through run context, cache,
checkpoint or import. Run snapshots must not bypass epoch/fencing protections.
Deletion removes new scoped content; audit/backup limits remain explicit. Export
must preserve new user-owned content in a versioned compatible extension or
explicitly disclose unsupported fields; never silently drop brief/lineage.

### User outcomes and implementation

All seven acceptance groups above have implementation and local/mock evidence.
`continuity.py` adds a small service, not a new executor or general RAG pipeline.
New runs use `workspace-aw06-v1`, one DBOS recovery owner and the existing agent
loop. They receive an exactly bounded **65,536-byte initial UTF-8 prompt**, which
includes user message, serialized manifest, fingerprint/byte fields, wrapper and
selected inventory. The cap does not include fixed agent instructions or later
tool outputs; existing token/tool/call/deadline/output budgets still apply to
those. This is not an estimate of provider tokenization or cost.

Explicit references pin original files and artifact versions; invalid or excessive
selection fails clearly. Automatic lexical selection considers at most eight
resources, begins with excerpts up to4,000characters and discloses omissions.
Further scoped reads are tracked, not described as semantic comprehension.
Recent complete conversational pairs are quoted as reference data rather than
replaying unbounded SDK history. Only current brief/memory generations are reused.
The full visible transcript remains saved, separately from execution authority.

Users can save goal, decisions and remaining work with CAS/idempotency; the agent
does not silently write confirmed project memory or verify these notes. Changes
invalidate reusable context and stop active consumers of the older brief/memory.
The UI explains this effect. Explicit source replacements link two already-uploaded
immutable originals; they do not mutate bytes or certify source truth.

Publication records actual input excerpts/tool read ranges and exact versions.
Freshness walks recorded upstream dependencies within128nodes; unavailable or
untracked lineage remains unknown. Unrelated outputs are not invalidated wholesale.
Live replacement annotations are shown separately from the immutable run snapshot.
Continue pins a precise output revision. Contiguous versions written by the same
run may be read/repaired within its original budget; a manual revision interleaved
in that chain fences later writes. Cancelled/failed work cannot overwrite a valid
current version or escape a stale target by creating an unrelated output.

Snapshot v1 export has a versioned optional `continuity.json` extension. The new
importer still accepts old snapshots. Brief and source links restore into fresh
scoped IDs; old dependency claims are archived untrusted metadata, **not** live
read lineage or authority. Older strict importers may reject the new extension;
this is not a claim of backward acceptance by an unmodified old app. Workspace
deletion purges the six new scoped continuity tables. It does not erase DBOS audit,
private backups or previously downloaded copies.

The compact Context panel reuses the AW-05 shell, bottom composer, artifact editor
and related-information rail. Choices/drafts remain scoped across workspace switch,
reload and process restart. No claim cards, new approval ceremony, model reviewer,
embeddings, universal plan IR, multi-agent runtime or legacy pipeline was added.
