## 1. Focused document and table editing

Preserve canonical Markdown/rectangular UTF-8 CSV and existing byte/cell limits.
Document edit mode provides a text selection/paragraph-focused editor with live
safe preview, explicit apply-to-draft and full Markdown escape hatch. No lossy
contentEditable HTML->Markdown roundtrip. Ambiguous or invalid selection must not
change unrelated text. Distinguish draft preview from saved version.

Tables have keyboard-labelled string-valued cells, rectangular TSV/CSV area paste,
bounded rendering/paging, no silent clipping/repair/type coercion/evaluation.
Preserve Unicode, embedded quoting/newlines, leading zero IDs, decimals and units;
formula-like text remains text, never executable. Large or malformed paste fails
atomically with the draft retained. Allow basic safe shape editing if needed for
a usable paste path, without Excel calculation/sort/filter scope expansion.

Draft-scoped bounded undo/redo for focused/raw/grid edits and explicit save-new-
version. Undo cannot undo a committed server version or reach into another
artifact/workspace; instead a later explicit save creates a new version. Reload,
switch, two tabs, stale save and storage exhaustion preserve recoverable work.
No duplicate editor IDs or optimistic success before server acknowledgement.

## 2. Reviewable agent edits

Add an explicit optional review mode when asking to edit a saved artifact. Existing
ordinary chat/read/create paths must not acquire new approval gates. A pending
candidate is not the current published version and must be visibly distinguished.
Reuse the existing agent tool where a small opt-in run context can safely intercept
edit output; do not add a second agent loop. Backend proposes the exact API/context
seam to Contractor and Web Builder before integration. Old runs without the option
retain their old semantics; if replay topology changes, version/drain explicitly.

Server owns candidate, base artifact/version/content hash, actor/workspace, run
provenance, bounded diff and state. Never trust client-authored base text, actor,
approval boolean or diff to change saved state. Show full proposed content and
non-overlapping bounded changes; accept all or selected independent change IDs,
or reject. Applying a selected subset is one atomic new version based on the exact
current base. No fuzzy application, silent rebase or old-version overwrite.
Reject malformed/overlapping/duplicate/foreign IDs, changed arguments, stale base,
cancelled/failed/in-flight producer, revoked/deleted scope. ACK loss/retry yields
one logical decision/version, not duplicate publication. Preserve the proposal
and good existing output on conflict; explain the next step.

Integrate workspace deletion/privacy epoch cleanup, artifact lineage and snapshot
boundaries. Deleted memory/context must not survive through an overlooked pending
proposal cache/table. Full private backup may preserve captured candidates as
private state; handoff and content import must never turn them into approved
authority or live jobs. Existing uncertain external effects remain fenced.
Explicit fixture commands prove transport only; they are not natural AI.

## 3. Selective handoff

New bounded owner-scoped endpoint selects saved artifact IDs, exact versions and
supported export formats (max10 entries, one logical selection per artifact by
default). Existing workspace snapshot export remains unchanged. A handoff contains
only chosen saved outputs and a format-v1 manifest of selected versions, logical
content/export hashes and known capture metadata. No conversation, memory, grants,
sessions, proposals, credentials, runtime DB or unselected sources by default.
Do not invent provenance for manual content or import authority from a manifest.

Snapshot selections consistently, bound CPU/memory/archive bytes, use safe generated
member names, no disk filesystem references, no network/font fetch. Validate scope
before parsing/rendering, recheck deletion/epoch boundaries before delivery. Missing,
foreign or deleted selection fails the whole request rather than silently dropping
files. Exporting an intentionally selected older version is allowed and labelled;
unsaved edits never enter a saved-version handoff. Ensure parse/readback of generated
DOCX/XLSX/PDF where supported, not just successful HTTP/ZIP generation. Retain CSV
injection protection without corrupting canonical string values; disclose existing
export limitations. Per-format work reuses current formats.py.

## 4. Compatibility and operational boundaries

## Completion report, 2026-10-29

Implemented the coherent co-editing and deliverable-review outcome on the AW07
foundation. No new harness, runtime agent hierarchy, DBOS step or ordinary
chat/read approval gate was introduced. Existing storage, versions, scope epochs,
renderers, recovery, BFF and neutral frontend were reused.

- **Focused editing:** select an exact region or paragraph, stage a replacement,
  inspect a safe live preview, explicitly apply to the browser draft and save a
  new version. Raw Markdown remains available. Unapplied replacement/paste work
  survives mode changes, unrelated edits, reload and editor remount.
- **String tables:** labelled cell grid and atomic rectangular CSV/TSV paste;
  quoted newlines, Unicode, zero-prefixed IDs, decimal commas and formula-like
  text remain strings. Saved preview and grid both page at 20 rows/8 columns rather
  than mounting 20,000 fields. No calculation, coercion or silent clipping. Draft
  undo/redo coalesces typing, with 20 snapshots and a 1MiB ceiling per history stack.
- **Review before publication:** opt-in `review_edits` reuses the current artifact
  tool path. A candidate is not a saved output. Accept all or selected logical
  line/CSV-row changes against the server's exact base/hash, or reject. A partial
  decision creates one atomic version and closes that candidate. Lost ACK replay
  returns the same receipt; stale/foreign/revoked/changed-argument cases cannot
  publish. Stale or blocked candidates can still be dismissed without revealing
  forbidden bodies or changing saved work. Deleting private context removes its
  pending candidate bodies and cached authority.
- **Selective handoff:** choose distinct saved outputs, exact versions and
  formats. Bounded ZIP and manifest contain selected deliverables, hashes and
  honest capture metadata, not conversations, memory, proposals, sessions,
  grants, runtime databases or unselected sources. DOCX/PDF/XLSX were parsed back
  for tested values; existing CSV injection protection and export warnings remain.
- **Compatibility:** application `0.1.0-aw08`, format marker 2 and data contract
  `workspace-data-aw08-v1`; execution topology stays `workspace-aw06-v1`. A
  stopped, backed-up AW07 catalogue requires explicit supported upgrade. Old
  workers must not share it. Private restore retains a pending candidate as
  unpublished state; only a later explicit decision publishes. The neutral
  source kit now includes the existing licensed Noto fonts required for PDF.
- **Retained demo:** privately backed up the idle owned demo, explicitly upgraded
  its metadata and restarted at <http://localhost:3120/workspace>. Integrated-
  browser reload confirmed the old synthetic project, both source originals,
  output version 1, selected context and unsent composer text remained. Manual
  verification changed only the visible editor mode, not document or draft text.
