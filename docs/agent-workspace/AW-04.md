## Outcomes and smallest useful implementation

- **Start without a fixture manual:** truthful availability, setup/readiness
  instructions, natural task starters in real mode, distinct simulation copy.
  Server-side model config and explicit external-processing opt-in; no keys in
  browser localStorage, prompts, model history, logs, exports or Git. A safe local
  CLI may collect secrets via terminal getpass and store only a private opt-in
  configuration file. No web credential submission required for this milestone.
  Profile changes require restart/drain, not mutation of an active agent topology.
- **Provider correctness:** support a pinned OpenAI Responses adapter because
  current Sol tool calling requires Responses, not Chat Completions. No hidden
  built-in web/file-search/shell/MCP tools. Only application-owned scoped tools.
  API storage disabled where supported; no default telemetry. Unknown dispatch
  never blindly replays; explicit total budget is shared by pilot and baseline.
- **Own your local data:** consistent bounded workspace export including original
  sources and artifact versions with metadata, without credentials/session hashes.
  Explicit destructive confirmation for deletion; purge/inaccessible application
  data, tombstone identity, stop/fence background/replay, cross-owner denial,
  stale delete and lost-ACK idempotency. Preserve unrelated workspaces. Disclose
  retained DBOS audit/private backups; do not claim forensic or provider erasure.
  Active or unsettled effects must not silently be dropped to enable deletion.
- **Pilot packaging:** one neutral loopback launcher/doctor path independent of
  legacy services, pinned dependencies, concise start/recovery guide, clear
  unavailable/permission/quota/recovery errors. Keep Docker and public production
  setup out. Avoid project copies or a new Next distDir.
- **Validation:** freeze twelve synthetic/public journeys, two non-RtR domains,
  six development and six held-out variants. Preserve all failures. Direct agent
  baseline uses the same model, data, scoped tools and budgets where meaningful,
  but explicitly lacks Workspace journal/UI/version persistence. Never call a
  tool-enabled agent a bare LLM. Some injected transport faults are operational
  checks, not model semantic failures. Separate deterministic, real-model, AI
  review and human review results. Do not invent active human minutes.

## Completion and verification

### User outcomes

The local pilot starts with `.venv/bin/workspace launch --simulation` from
`v2/apps/workspace`. The launcher starts only the loopback API/UI, not Docker,
legacy services or an external model. Model & setup makes simulation, missing
credentials and external-processing consent visible before a request. Private
setup uses terminal getpass and an explicitly selected 0600 profile; neither the
browser nor exports receive that profile. Configuration/doctor is not a model
connectivity test. Provider wiring uses pinned OpenAI SDK 3.31.0 and Responses,
with store=false, bounded output, SDK retries off and no hosted tools.

Workspace data can export originals, extracted text, all artifact versions,
conversation and explicit memory with a digest/length manifest. A consistent
20MiB/2,500-member ceiling is enforced. Deletion uses a five-minute snapshot-bound
preview, exact name, owner/workspace binding and idempotency key. Busy/uncertain
effects block deletion with recovery guidance. Tombstones fence indirect reads,
late callbacks and stale restored rows, including background dispatch. Valid
unrelated workspaces remain intact. Application deletion does not erase retained
DBOS audit, private backups, downloaded copies or synthetic outbox receipts.

The evaluation package freezes twelve assistant-authored synthetic journeys in
two non-RtR domains. It provides a same-model direct **tool-enabled agent** arm,
offline plan/rubrics, explicit semantic-only capture and a shared persistent
pre-dispatch budget. Unknown charges remain reserved and stop the campaign.
Authority is tied to corpus/model/endpoint/cases and an absolute ledger path;
ordinary interactive UI runs cannot spend it. This is a trusted local-operator
control, not an account-wide billing firewall. Smoke/repair must share the ledger.
No authorization file or real key was fabricated. The proposed $10 ceiling is
still a proposal, not spend already approved or performed.
