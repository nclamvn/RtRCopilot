### Invariants and implementation boundaries

- Reuse AW-01's neutral API, scoped catalogue, version receipts, event journal,
  native durable owner, budgets, cancellation fence and UI. No legacy RAG or
  ActionService becomes the workspace kernel.
- Migrate the existing local catalogue additively and preserve stored workspace,
  source and artifact bytes. Version the changed agent/tool topology; do not
  silently replay old workflow history through incompatible code.
- Read, preview, download, diff, revision and render all enforce current local
  owner/workspace boundaries. Client IDs, file contents and fixture web metadata
  never grant additional authority.
- Source imports and exports have byte/count/page/cell/time limits. Reject
  encrypted, malformed, unsafe or unextractable content explicitly. Preserve
  useful supported text with coverage warnings for harmless presentation limits
  where feasible; do not reject ordinary headers/footers just for being present.
  Never present an empty, partial or truncated extraction as the complete file.
- Renderers operate on a frozen artifact version, never mutate a canonical
  draft while exporting, and do not replace valid drafts after render failure.
  No RtR branding, hardcoded proprietary content, host-path tools or system
  credential discovery enters the output path.
- Render representative exported documents and inspect every representative QA
  page. Font, numbers and complete supported content matter more than original
  pagination. Preserve distinctions between structural and visual checks.
- XLSX/CSV are data-table formats for this milestone, not a certified financial
  calculation engine. Do not silently evaluate external links or macros, strip
  existing formulas from the retained original, or claim missing cached values
  as verified totals.
- Fixture research exposes only the registered synthetic collection. Arbitrary
  URLs, private network targets and external redirects do not become available
  through an untrusted message or uploaded document.
- Existing local binding and default-disabled BFF remain intact. No public
  deployment, new identity system, scheduler, memory, MCP or agent swarm.

sources; documents and tables from multiple sources; DOCX/PDF/XLSX roundtrip;

IDs; hostile XML/ZIP/formula/URL content; unsupported scanned/encrypted files;
AW-01 restart/stop/reconnect regression; keyboard/mobile/axe checks.

No large benchmark or claim of superiority over a direct agent is implied.
Measure the relevant deterministic paths and user actions where feasible;
real-model quality, provider price/latency and true productivity advantages are
UNMEASURED. No extra reviewer model or fallback external service may be added to
make a fixture pass. Keep the implementation local and the feature scope finite.
